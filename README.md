# Last Stop - playtest builds

Tester builds of **Last Stop**, a first-person horror game by Witchbrew Productions.
This repository holds only the downloads: no source code.

## Get the newest build

Open **[Releases → Latest](../../releases/latest)** and download the `.zip` under **Assets**.

1. Unzip the whole folder somewhere (don't run it from inside the zip).
2. Open `READ ME FIRST.txt` for the controls and what's new.
3. Double-click `LastStop.exe`.

Older builds stay on the [Releases](../../releases) page.

Please keep these builds to yourself: don't share the files or the link.
